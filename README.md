## 주요 기능

**■ 외식비** **내역 입력 기능**

- 유저가 하나의 중요 지출 `외식비`에 집중할 수 있도록 도움.
- 지출을 입력하면, 계산기 앱으로 이동할 필요 없이 목표 금액을 기준으로 자동으로 계산
- 지출 입력 시, 방문식당/메뉴/만족도/지출비를 입력 → 식당 추천 알고리즘에 반영

**■ 지출 관리 캘린더 & 목표 금액 달성률 시각화**

- 달력을 통해 주간/월별 자신의 지출 기록 확인
- 목표 달성률을 시각화하여, 남은 지출 금액을 한 눈에 파악

**■ 커뮤니티 기능**

- 서로의 지출 내역을 공유하고 칭찬 이모지를 통해 상대방을 칭찬하는 기능
- 본인이 소비한 내역이 커뮤니티 피드 페이지에 자동으로 공유
- 다른 유저로부터 받은 이모지를 통해, 목표 달성을 향한 의욕 증진

**■ 가성비 식당 추천 서비스**

- 사용자 기반 협업 필터링 알고리즘을 이용하여 식당 추천
- 유저와 취향(선호 카테고리)이 비슷한 다른 사용자의 식당 평가와 주간 목표 금액을 통해 하이브리드 방식으로 알고리즘 구성
- 식당 상세 페이지로 이동하여 식당 정보 확인
